AZEROTH SURVIVORS - CO-OP LOBBY PREVIEW

IMPORTANT: This is a standalone Windows networking/lobby TEST.
It is NOT yet integrated with the Azeroth Survivors playable EXE.

1. Extract all files in this package together.
2. Double click Launch-Lobby.bat.
3. Host chooses 1. The host also connects as Player 1.
4. Up to three friends on the same LAN choose 2 and enter the host's IP address.
5. Everyone types READY and presses Enter.
6. When everybody is ready, Player 1 types START and presses Enter.
7. The lobby announces STARTED. Actual gameplay is not launched yet.
8. Type QUIT to leave. Closing the host's separate server window ends the lobby.

Windows Firewall may ask the host to permit connections on private networks.
Uses TCP port 45454. Don't expose this experimental lobby to the public internet.
